## 已知边界（如实登记，不当作通过）

1. **示例只对已编排选项与少量同义短句作匹配**。超出范围的自由输入停在原步骤并提示「先选一个步骤」，
   不假装理解，也不标错推进。
2. **历史写作用态的截面**：示例会话的历史由「预置轮次 + 实际发生的轮次」重建，因此刷新后卡片可继续
   操作的是**当前步骤**；更早的卡片只回看（`live` 机制）。这与方案 §6「老卡用于回看，当前只存在
   一组可提交的学习动作」一致。
3. **科研端 WRITE 页有 1 个空 `src` 的 `<img>`**（页面自身的 PDF 预览占位）。基线与候选逐项一致，
   非本轮引入，不影响行为。
4. **`present_files` 之外未做录屏**；证据以当前状态截图 + JSON 结果为准。
5. 会话列表里既有 5 条采证记录与新增 7 条示例标题相近，二者是**不同 ID 的独立会话**（方案 §3 明确
   要求不要合并）。示例不占用「置顶」分组，落在「今天」分组打头；主持人手册已写明打开位置。
