## 7. 附：分类判定规则（本审计使用的口径）

- **现役一致**：run-01/run-02 的截图、DOM 文本或 API JSON 中能逐字/逐结构对上的元素。
- **需要恢复**：证据显示现役存在该路由/区块/控件/文案，而离线缺失、改写或数字冲突。
