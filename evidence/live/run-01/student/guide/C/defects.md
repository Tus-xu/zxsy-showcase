# 题3 缺陷登记（run-01 实拍）

## C-D1 第二轮起丢失题目上下文并串到无关资料例
- 缺陷锚点/截图：main 04-turn-01.png
- 现象：学生「抽到 2、2、5 时，X=2」后，平台称缺上下文，转而引用「同时掷两颗骰子、X=max{X1,X2}」的教材例 4，离开当前题。
- 影响：引导多轮连续性不可靠，演示会在第二轮跑题。
- 复现动作：C 主线/分支持续逐轮作答（见 transcript.md 输入原文）

## C-D2 收束轮未确认最终结论
- 缺陷锚点/截图：main 07-turn-04.png
- 现象：学生给出「五个号码地位相同，E(X)=5×61/125=61/25=2.44」后，平台只追问前提「五个号码地位相同是怎么来的」，未确认最终答案。
- 影响：没有明确收束，主线以追问结束。
- 复现动作：C 主线/分支持续逐轮作答（见 transcript.md 输入原文）

## C-D3 错答追问时先插入无关错题记录
- 缺陷锚点/截图：branch-wrong 05-turn-02.png
- 现象：「我哪里错了」后，平台先列导数定义/集合等历史错题，再回到本题有放回/无放回混淆的解释。
- 影响：纠错回答被无关内容打断，但最终诊断正确。
- 复现动作：C 主线/分支持续逐轮作答（见 transcript.md 输入原文）
