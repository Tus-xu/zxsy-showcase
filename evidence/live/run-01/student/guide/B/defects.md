# 题2 缺陷登记（run-01 实拍）

## B-D1 学生发言被当作题面（题干），结构化引导面板无法用文字推进
- 缺陷锚点/截图：main 05-turn-02.png、06-turn-03.png、07-turn-04.png
- 现象：学生第 2 轮发言「面 AA₁D 内过 D 与侧棱平行的直线垂直底面，也垂直 BC」被平台放进「读题理解」题干区并要求圈点；后续轮次只回「填空补全」面板，文字作答无法推进，主线停在中途。
- 影响：自动采集中纯文字作答不能走完引导流程；对现场演示，题目若进入结构化引导，主持人必须改用圈点/填空交互。
- 复现动作：B 主线/分支持续逐轮作答（见 transcript.md 输入原文）

## B-D2 部分答案误判：只选 B 被判为正确，未指出 D 亦成立
- 缺陷锚点/截图：branch-wrong 04-turn-01.png
- 现象：学生「我只选 B」后平台回「选B是正确的！」并按正确收束，未指出本题 D 选项同样成立，漏判部分答案。
- 影响：多选/多判断场景会把不完整答案判对，评分结论不可信。
- 复现动作：B 主线/分支持续逐轮作答（见 transcript.md 输入原文）
