1. 三题上传/视觉识别可用，**首轮平台复述与题型判断均可作为实拍素材**。
2. 多轮引导在现役系统里不稳定：A 丢题、B 被交互面板截断、C 收束缺确认。按实施方案 §4，这三题的主线更可能需要「策展改写/策展补制」，而非原样实录；首轮 OCR/复述可原样保留。
3. B 的「结构化圈点/填空」交互是真实产品形态，离线展示若要还原引导流程，需要还原该面板交互，而不能只放文字对话。
4. 求助分支（三题）表现正常，可作为原样实录候选；错答分支只有 C 具备可用的正确诊断，A/B 需改写或补制。
