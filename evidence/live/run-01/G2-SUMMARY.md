## 跨端链路结论

- **发布 → 学生可见（本轮新版本）：不成立。** 教师在现役备课中心无法确认教学路径、无法生成课件、无法发布；学生端当前可见的「函数的单调性：从图像到导数」是既有种子课件，不是本轮编辑内容。原因链：无授权教材 → AI 提案类型前端不支持 → deck/blueprint 为空 → 发布按钮 disabled。
- **批改 → 学生可见：读链路成立、写链路待复核。** 学生端能读到同一提交的批改结果（总分 30、逐题分、作答），刷新保持；但教师本轮终审给分/评语未在学生端核验到变化。
- **科研导入 → 阅读/写作：导入成立，阅读与写作不可用**（PDF 渲染空白、编辑器不可交互）。
