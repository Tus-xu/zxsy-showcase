### 7.3 对话页 / 上传态（三题对照基准）
- 对话头：标题（新对话 → 发送后自动变为「分析用户上传的文件」）+ 副标题「学习对话 · 基于当前上下文与学情回应」；右侧步徽标胶囊（「新对话」/「对话中」/「第 N 步 / 共 M 步 · 引导中 · 提示档 窄追问」+ 知识点「圆锥曲线」）
- 输入区结构（从上到下）：附件行 `.ci-attach-row`（仅在有附件时出现）→ 白色玻璃卡 `.ci-box` → textarea（placeholder 原文「输入数学问题，Enter 发送，Shift+Enter 换行；可直接粘贴截图」，maxlength 4000）→ 按钮行：回形针（title「上传附件（pdf/图片/office/md/txt，≤20MB）」）、相机（title「拍照识题」）、书本（title「引用知识库资料」）、麦克风（title「语音输入（文本转公式）」）、思考开关（title「思考模式：关（快速响应）\n点击开启，可看模型思考过程」）、弹性空白、字数「0/4000」、发送按钮「发送」（disabled 无内容/有未就绪附件；流式时变红色「停止」）
- 附件卡片（关键！）：`min-width:180px; max-width:260px`，横向 flex：40×40 缩略图（blob URL，点击 lightbox）+ 文件名（加粗、省略号、title 全名）+ 状态行；状态文案状态机：`计算摘要…`（spinner）→ `上传中 {n}%`（含进度条）→ `待解析…` → `解析中（{engine}）`（spinner）→ **`✅ 已就绪 {engine}`**（绿色，engine 如 `mimo_vision`）→ 失败 `❌ {错误文案}` + `↻` 重试 + `×` 移除；就绪卡绿边 + 浅绿底；失败卡红边 + 浅红底

### 7.5 交互与状态细节
- 上传入口两处：① 首页「📷 拍一道不会的题」卡片点击直接触发隐藏 `input[type=file]`（accept `image/jpeg,image/png`，非 multiple）；② 输入条相机图标 `button[title="拍照识题"]`（同一个隐藏 input）
- 文件选择后立即显示本地缩略图（objectURL），随后才上传解析；解析轮询间隔 2s 起、指数退避至 30s
- 发送按钮可用条件：草稿非空 **或** 存在 `parsed` 附件；空文本发送时前端补「请分析我上传的文件」
- 附件上限 3 个；超限 toast「单条消息最多 3 个附件」；不支持类型 toast「不支持的文件类型：…」；限流红字「操作频繁，稍后可传」
- 会话刷新后保持：历史消息、附件文件名、步徽标「第 N 步 / 共 M 步 · 引导中…」、错题/学习数字均保留（PDF/DOM 见 `api/guide-results*.json` 的 persistence 段）
