## ④ 失败/阻塞清单（含平台原话）

1. **A · 重复追问 + 题面误读**（现役缺陷，非采集问题）
   - t1-t2 平台原话：**“题目里除了‘虚轴长是实轴长的 √7 倍’，还有没有别的条件？…光有 b/a=√7 这一个关系，双曲线的‘形状’是定了，但大小（a 具体是多少）还没定”** → 把“求离心率比值”误判为“缺定大小条件”。
   - t6 与 t9 问法几乎相同：**“在双曲线里，a、b、c 之间有一个固定的关系式，你还记得它长什么样吗？”** → 第 9 轮重复第 6 轮，出现引导环。
   - t7 因两步 expr_input 判错触发补课，补课知识点错配：**“你卡在这一步，多半是「任意角与三角函数定义」还没打牢”**（题干是圆锥曲线，却补三角函数）。
2. **B · 门禁错报“没有题目”**
   - t1 平台原话：**“我还没看到题目——引导式解题需要先有一道题。你可以拍照上传、把题目打出来…”**——此时附件已显示就绪且学生已描述题目（附件解析文本未进 socratic 上下文）。
3. **B · expr_input 目标式与提问不一致（判定器 bug）**
   - 第 2/5 步提问：“BC 除了垂直于 AD，还和平面内哪一条直线有垂直关系？”
   - 同卡 keypad 只下发 `AA / 1 / D` 三个 token（目标式被 `extract_math_expr` 抽成 `AA_1D`），与提问要求的“BC⊥AA₁（还需 BC⊥AD 且两线相交）”不匹配；学生写数学上正确的 `BC\perp AA_1` 也被判错。
4. **C · 判定器只认“目标式单式”，未收 E(X)**
   - t7 学生给出指示变量完整推导（P(Xᵢ)=1−64/125=61/125，E(X)=5×61/125=61/25），平台仍认为“没说明 X=1 的关系”，转示范确认；示范后转问 X=3，未完成 E(X) 收束。
5. **环境事故**
   - 采集期间 Docker Desktop 停止 → 依赖容器退出 → API 8000 不可用：登录页报 **“响应解析失败 (HTTP 500)”**、会话中断，A 会话被迫重建（t00–t04 与 t05–t09 属两个会话，flow 中如实保留；`upload/parse` 响应因此未落盘，file_id 从首轮请求体还原并在 flow 中注明）。
   - 恢复（lead 重启容器）后继续，B/C 上传/解析响应完整落盘。
6. **采集器自身问题（如实记录，不掩饰）**
   - A 的 t01/t02 为**同一段文字重复发送**：队列控制器在环境恢复后重启时重放了队列（无游标持久化），造成一次重复提交；已在 A flow 与 `note` 标注。此后已改为清空队列+隔离轮次目录，B/C 未再发生重复（B/C 每轮 expr 各不相同）。
   - 交互卡「填空」的自动化在点选后读取选项文本超时（`.ix-cz-opt` 面板已关闭），C 的 t4 由“填 `=` → 点填好了”两步完成，属于真实 UI 动作。
