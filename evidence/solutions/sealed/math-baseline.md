## 三、封存答案与判定规则

### A · 双曲线离心率（单选）

- 题面：若双曲线 C 的虚轴长为实轴长的 √7 倍，则 C 的离心率为（A √2 / B 2 / C √7 / D 2√2）
- **标准答案：D，e = 2√2 = √8**
- 可接受等价：`D`、`2√2`、`√8`、`e=2√2`、`e²=8`（单独提交平方值时允许继续求 e）
- 推导：2b=√7·2a ⇒ b/a=√7；c²=a²+b² ⇒ e²=1+(b/a)²=8 ⇒ e=2√2
- 典型错答：C（把 b/a 当 e）；A（忽略 √7 倍，默认等轴）；B（把 √8 误化简为 2 / 把 7 当作 3）
- 易错根源：轴长与半轴长混淆；c²=a²+b² 与 a²=b²+c²（椭圆式）混淆

### B · 正三棱柱中的线面关系（多选）

- 题面：正三棱柱 ABC−A₁B₁C₁ 中，D 为 BC 中点，则（A AD⊥A₁C / B BC⊥平面 AA₁D / C AD∥A₁B₁ / D CC₁∥平面 AA₁D）
- **标准答案：B 与 D 均成立（完整集合 {B, D}）**
- 可接受等价：`BD`、`DB`、`B,D`、`{B,D}`、文字"B 和 D"；只选 B 或只选 D 记为**部分正确**
- 推导：底面正三角形中 AD⊥BC；AA₁⊥底面 ⇒ AA₁⊥BC；BC⊥AD、BC⊥AA₁、两线相交 ⇒ BC⊥平面 AA₁D（B 对）。CC₁∥AA₁ 且 AA₁⊂平面 AA₁D，C∉平面 ⇒ CC₁∥平面（D 对）。AD·A₁C=3≠0 ⇒ A 错；A₁B₁∥AB 与 AD 成 30° ⇒ C 错。
- 典型错答：只选 B（漏面外条件/平行传递）；只选 D；选 A（"看起来垂直"）；选 C；全选
- 题型注意：原图未印单选/多选说明；按内容判定为多选。展示版必须支持组合选择，不能强制单选。

### C · 有放回取球的期望（填空）

- 题面：箱中 5 球编号 1~5，有放回取三次，至少取出一次的球的个数为 X，求 E(X)
- **标准答案：E(X) = 61/25 = 2.44**
- 可接受等价：`61/25`、`2.44`、`305/125`、`5*(1-(4/5)^3)`；近似值 2.4 不接受
- 推导：E(X)=5·P(某号至少出现一次)=5·(1−(4/5)³)=5·61/125=61/25
- 典型错答：3（当无放回）；61/125（漏乘 5）；183/125（系数用 3 次）；69/25（X=2 计数未扣全同）
- 另一条有效路径：按 X=1/2/3 枚举 125 个有序结果（5 + 60 + 60），加权得 61/25，判对。
