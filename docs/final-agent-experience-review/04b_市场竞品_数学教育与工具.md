## 1. Desmos（Graphing Calculator）

- **入口**：https://www.desmos.com/calculator
- **版本**：网页版，2026-11-25 访问（页面未展示版本号）。
- **复现步骤**（脚本 `run-desmos.cjs`）：
  1. 打开计算器，等待画布与表达式栏加载；
  2. 点击首个表达式输入区，键入 `f(x)=x^3-3x`，回车；
  3. 在新表达式行键入 `(1,-2)`、回车；再键入 `(-1,2)`、回车，标出两个极值点；
  4. 键入 `a=1`、回车，生成滑动参数；
  5. 键入 `g(x)=x^3-3x+a`、回车；
  6. 点击滑动条轨道右侧，使 `a≈8.7`，观察红色曲线相对黑色原曲线上移。
- **截图与观察（已 Read 核对）**：
  - `desmos-03-extrema-points.png`：表达式栏用 **MathQuill 排版**显示 `f(x)=x^3-3x`、`(1,-2)`、`(-1,2)`；每条表达式左侧有与图形对象一致的颜色图标（红色曲线、蓝色点、绿色点）；画布上两个极值点是实心圆点，坐标与表达式栏一致。
  - `desmos-05-parameterized-curve.png`：新增紫色滑块图标与 `a=1`；画布同时显示黑色 `f` 与红色 `g(x)=x^3-3x+a`；滑块范围为 -10…10。
  - `desmos-06-slider-a-changed.png`：滑块值变为 `a=8.7`，红色曲线整体上移；原函数与两个极值点保持不动。参数改变是**即时**的，无“重新计算”按钮。
- **设计要点**：
  - 图形工具本身**不提供解释文字**；“图形如何与解释结合”要靠外部内容（如 Mathos 将其嵌入解题回答）。
  - 颜色不是装饰，而是**对象身份编码**：表达式图标、图线、点一一对应，用户可用颜色追踪对象。
  - 数学排版（上标、负号、括号）在输入框内即为排版态，不是纯文本。
- **对本项目参考**：可复用“表达式列表 + 颜色芯片 + 即时参数”的图形卡结构；不复用其品牌与整页工具型布局。
- **无法验证**：无障碍读屏表现、离线可用性、移动端手势、账号态下的保存/分享。

## 2. GeoGebra（Calculator Suite）

- **入口**：https://www.geogebra.org/calculator
- **版本**：网页版 Calculator Suite，2026-11-25 访问（页面未展示版本号）。
- **复现步骤**（脚本 `run-geogebra3.cjs`，最终证据由页面内官方 `ggbApplet` API 设置构造）：
  1. 打开 Calculator Suite，等待 Algebra 与 Graphics 加载；
  2. 执行 `f(x)=x^3-3x`；
  3. 执行 `A=Extremum(f)`，得到 `A_1=(-1,2)`、`A_2=(1,-2)`；
  4. 执行 `g=Tangent(0,f)`，得到 `g: y=-3x`；
  5. 执行 `h(x)=f'(x)`，得到 `h(x)=3x²-3`；
  6. 隐藏虚拟键盘，等待重绘后截取整页。
- **截图与观察（已 Read 核对）**：
  - `geogebra-01-calculator-empty.png`：左侧 Algebra 栏（含 `+` 输入行）、右侧网格画布、底部虚拟键盘；顶部 `GeoGebra Calculator Suite / Graphing`。
  - `geogebra-03-extremum-command.png`：代数栏显示 `f(x)=x^3-3x`、`Extremum(f)` 与 `A_1=(-1,2)`、`A_2=(1,-2)`；画布上两个灰点带 `A_1/A_2` 标签；函数为青色。
  - `geogebra-04-tangent.png`：`g: Tangency(0,f)`、`= y=-3x`；画布出现灰色切线，与曲线在原点相切。
  - `geogebra-05-derivative.png`：`h(x)=f'(x)=3x²-3` 以红色抛物线显示；函数青色、切线灰色、导数红色，代数栏颜色芯片与图线一致。
  - `geogebra-06-api-verify.png` 与 `geogebra-07-clean-view.png`：`t2=f(1)=-2`、`t3=h(1)=0`，证明对象数值正确；clean view 是隐藏键盘后的完整桌面布局。
- **异常与修正（必须记录）**：首次“点输入行 + 键盘输入”的运行中，画布出现与 `f(x)=x^3-3x` 不符的曲线，且 `Extremum` 显示异常；用 `ggbApplet.getValueString('f')`、`f(1)` 校验后确认函数定义/数值正确，重跑并等待重绘后图形恢复正常。因此**不把首次异常截图作为产品表现证据**，只保留校验通过的截图。
- **设计要点**：代数栏与图形是同一对象的两种表示；点击/输入命令后两侧同步更新；颜色芯片用于跨面板追踪；命令结果（极值点、切线方程、导函数）以**精确数学对象**呈现，而不是图片。
- **对本项目参考**：数学组件应同时给出“图形 + 代数精确值”，并允许用户用命令或滑块操作；但课堂场景不应要求学生学习 GeoGebra 命令语法。
- **无法验证**：CAS 完整能力（`Derivative(f)` 在 Calculator Suite 报 “CAS commands not loaded yet”，故改用 `f'(x)`）；账号保存、3D、移动端。

## 3. JSXGraph 1.14.3（官方示例）

- **入口**：
  - https://jsxgraph.org/ （官网，1.14.3）
  - https://jsxgraph.org/share/example/antiderivative
  - https://jsxgraph.org/share/example/all-real-roots-of-a-polynomial
- **复现步骤**（脚本 `run-jsxgraph.cjs`、`run-jsx-anti2.cjs`）：
  1. 打开 Antiderivative 示例，记录初态 `J=0.0000`；
  2. 通过页面内官方 JSXGraph API 将自由点移动到 `(1.6,3.2)`（无头 Chrome 下鼠标拖拽未命中，见下），得到 `J=39.6058` 与阴影面积；
  3. 打开 All real roots of a polynomial 示例，记录 `a=0.00,b=-5.00,c=2.00,d=1.00` 与实根 `A/B/C`；
  4. 将 `d` 滑块从 1.00 拖到 10.00，实根标记消失，曲线形状改变。
- **截图与观察（已 Read 核对）**：
  - `jsxgraph-04-antiderivative-dragged.png`：页面上方是说明文字“Dragging the black point shows that the antiderivative of the parabola looks like a polynomial of degree 3.”；中间实时画板显示阴影面积、`J = 39.6058`、橙色辅助点；下方是完整 JavaScript 源码（可复制）。
  - `jsxgraph-05-polynomial-roots-initial.png`：说明文字给出四次多项式公式 `f(x)=x⁴+ax³+bx²+cx+d`，并说明“The values of a, b, c and d can be adjusted with the sliders.”；画板内四个滑块与橙色实根 `A/B/C`。
  - `jsxgraph-06-polynomial-roots-changed.png`：`d=10.00`，实根 `A/B/C` 消失，曲线改变；滑块值实时显示。
- **设计要点**：官方示例把“**解释文字 → 可操作图形 → 源码**”三层放在同一页；图形对象（根、积分值）用橙色强调，坐标轴/曲线用低饱和蓝；滑块数值直接标在轨道旁。
- **对本项目参考**：可复用“解释—图形—可复算源码”的教学结构（源码可折叠）；不建议把源码直接暴露给学生端。
- **无法验证**：鼠标拖点在无头模式下的行为（已如实记录为 API 驱动）；触摸设备；不同构建版本的稳定性。

## 4. OATutor（自适应数学练习，公开 GitHub Pages 版）

- **入口**：https://cahlr.github.io/OATutor/
- **版本**：GitHub Pages 公开构建，2026-11-25 访问；页面未展示 commit/版本号。
- **复现步骤**（脚本 `oatutor-interact3.cjs`、`oatutor-wrongfirst.cjs`、`oatutor-correct.cjs`）：
  1. 打开首页，课程列表选择 `SJSU Calculus 1 (Quiz Collection)`（`View Course 3`）；
  2. 选择 `Lesson Quiz 1` 的第一个 `Select`；
  3. 进入练习：页面顶部为 `Lesson Mastery: 11%` 进度条；左侧为课程树；中部为题目卡；右侧为 `Hints` 与 `AI Tutor` 卡；
  4. 在答案输入格作答并 `Submit`；
  5. 点击右侧 `Hints` 展开提示列表，再点击 `Hint 1` 展开首条脚手架；
  6. 观察提交后的对/错图标、Toast 与掌握度数值。
- **截图与观察（已 Read 核对）**：
  - `oatutor-03-lesson.png`：`Lesson Mastery: 11%`（灯泡/猫头鹰吉祥物进度条）；题目“Find the least common multiple (LCM)… 12 and 18”；答案框带计算器图标；`Hints` 卡明确写出 **“Using hints will not increase mastery credit”**；`AI Tutor` 卡写明 **“Won't affect your mastery score”**；底部有 CC BY 4.0 来源署名。
  - `oatutor-05a-wrong-1s.png`：提交后 1 秒，右上角出现绿色 **“Correct Answer!”** Toast，掌握度变为 **39%**；页面已切到下一题（5625 的因数/整除选择题），绿色对勾出现在 Submit 旁。
  - `oatutor-06-hints.png`：`Hints` 展开为浮层，`Hint 1` 标题 **“Checking for Divisibility”**，内容 **“Is 5625 divisible by 2?”**；`Hint 2–5` 折叠，呈灰色未解锁态。
  - `oatutor-07-wrong-mcq-feedback.png`：故意选择错误选项 `2` 后，Submit 旁只有一个**红色叉号**，没有文字解释；掌握度仍为 39%。
  - `oatutor-11-mcq-correct-feedback.png`：选择 `3` 后 Submit 旁为**绿色对勾**，掌握度仍为 39%。
  - `oatutor-14-wrong-first-feedback.png`：新会话首题“Please factor 48.”，选择 `2,2,3,7` 提交，红叉，掌握度保持 **11%**。
  - `oatutor-15-hint-after-wrong.png`：展开 `Hint 1`，内容为 **“First, we need to find two factors whose product is the given number, which is 2 × 24.”**；`Hint 2–4` 折叠；掌握度仍为 11%。
- **关键发现（含异常，不掩饰）**：
  1. **答错反馈非常薄**：只有一个红叉，没有“错在哪一步/哪个条件”的文字诊断；真正的脚手架在右侧 `Hints` 中，需要学生主动打开。
  2. **提示是预写阶梯**：Hints 以 `Hint 1…N` 折叠列表组织，逐条展开；平台明确声明“用提示不会增加掌握度学分”，把“帮助”与“评分”分开。
  3. **掌握度可见但语义不透明**：进度条 + 百分比 + 吉祥物很醒目；一次提交可从 11% 跳到 39%，但界面没有解释这次跳变依据（哪项技能、权重多少）。
  4. **平台题目存在变体与会话差异**：同一 `Lesson Quiz 1` 在不同会话中出现 LCM、整除、因数分解等不同题目；一次会话中首题已预选 `3`，提交 `72` 后显示“Correct Answer!”并把掌握度从 11% 提到 39%。`72` 是否为该变体的正确答案无法从界面确认，**记为待核验的平台行为，不作为正确性结论**。
  5. **数学排版**：题干与选项用 MathJax 渲染（DOM 中同一数字出现“可视文本 + 排版文本”两份），选项文本抽取会重复；视觉上是正常数学排版。
  6. **颜色语义**：绿色=正确、红色=错误，仅在反馈图标和 Toast 上使用；题目/图表本身不用红绿表达数学对象，避免与对错语义冲突。
- **对本项目参考**：把“红叉”升级为“错误定位 + 同层提示入口”；提示阶梯与掌握度政策要显式可见；掌握度变化应能展开看到依据；不要把提示与评分混在一起。
- **无法验证**：登录态下的跨会话掌握度、教师端、题库正确性、提示内容的学科准确性（仅抽样一条）。

## 5. Mathos AI（含 MathGPT Pro 重定向）

- **入口**：https://www.mathos.ai/app/ask （官网首页 https://www.mathos.ai/）
- **版本**：网页版，2026-11-25 访问；页面显示 “3 Days Free Trial”“Log in here!”。
- **复现步骤**（脚本 `run-mathos.cjs`）：
  1. 打开 `/app/ask`，无需登录即出现聊天式解题界面；
  2. 在输入框键入公开题目：“Find the derivative of f(x)=x^3-3x and its local extrema.”；
  3. 回车发送，等待约 18 秒；
  4. 记录分步解答、答案框、内嵌图形与后续学习入口。
- **截图与观察（已 Read 核对）**：
  - `mathos-04-response.png`：回答按步骤展开：先写幂法则得到 `f'(x)=3x²-3`，再解 `f'(x)=0` 得 `x=-1,1`，用 `f''(x)=6x` 判定 `(-1,2)` 为极大、`(1,-2)` 为极小；**“Answer:”后的结果用方框排版**。
  - 回答中直接嵌入一个**可交互图形面板**（表达式栏 `y=x³-3x`、`(-1,2)` 红点、`(1,-2)` 绿点，界面与 Desmos 高度一致），并在图下方用一句话总结“Differentiated … illustrated on a graph.”。
  - 图与文颜色对应：红点=极大、绿点=极小，与文字中的极大/极小顺序一致；表达式栏左侧色点与图上点颜色一致。
  - 回答下方提供 `Create Flashcards / Create Quiz / Video Generation / Generate Graph / Similar Questions / Related Videos / Interactive Games` 等继续学习入口；右侧栏还有 `Zoom In` 与另一个画布区域。
  - 顶部/左侧可见试用与登录提示；回答语言为英文（即使浏览器 locale 为 zh-CN）。
- **设计要点**：这是本次观察中**“解释 + 图形”结合最紧**的产品：图形不是外链，而是回答的一部分；文字步骤、方框答案、图形对象三者共享颜色与数值。
- **对本项目参考**：高保真目标可直接借鉴“分步文字 → 方框结论 → 同卡内嵌图形（对象与文字同色）→ 继续学习动作”的纵向结构；但需离线自研，不能依赖外部嵌入。
- **无法验证**：图形组件是否为官方 Desmos 嵌入/授权、试用额度与登录后能力、图片题、多轮追问、中文回答质量。
- **MathGPT Pro**：`https://mathgptpro.com/` 实际 302 到 `https://www.mathos.ai/zh-CN`（截图 `mathgpt-redirect-mathos-01-official.png`）。因此本轮**没有获得独立的 MathGPT 产品界面证据**，不把 Mathos 的能力记到 MathGPT 名下。

## 7. 横向对照：五个重点问题

| 维度 | Desmos | GeoGebra | JSXGraph 示例 | OATutor | Mathos AI |
|---|---|---|---|---|---|
| 图形与解释结合 | 纯图形工具，无解释 | 图形+代数栏，无教学解释 | 说明文字+图形+源码同页 | 题干/选项为主，无图形组件 | **文字步骤+方框答案+内嵌可交互图形** |
| 答错反馈 | 无（无判题） | 无（无判题） | 无（示例不判题） | **仅红叉**，无文字诊断 | 未构造错答（本轮只验证正解） |
| 提示策略 | 无 | 无 | 源码即“解释” | **预写 Hint 1…N 折叠阶梯**；提示不计掌握度学分 | 分步解答即提示；未验证“只给提示”模式 |
| 学习状态呈现 | 无 | 无 | 无 | **顶部百分比进度条+吉祥物**；课程树显示 0% | 无掌握度；有试用/登录状态 |
| 数学排版与颜色语义 | MathQuill；对象色=表达式色 | 代数栏精确对象；色芯片=图线色 | 公式+滑块数值；橙色=根/积分 | MathJax；红/绿只表对错 | KaTeX 风格；红=极大、绿=极小，与图一致 |

### 7.1 结论

1. **“图形工具”与“教学解释”在市场上是分离的**。Desmos/GeoGebra/JSXGraph 提供可靠的对象化图形，但不提供教学叙述；Mathos 的做法是把图形作为回答的一部分嵌入，并用同一套颜色把文字结论与图形对象绑定。这是本项目最值得复用的结构。
2. **答错反馈普遍弱于提示系统**。OATutor 的红叉没有任何“错在哪”的文字，学生必须自己想到去点 Hints；其 Hint 1 是具体的下一步问题（“Is 5625 divisible by 2?” / “find two factors whose product is … 2×24”），属于**过程性脚手架**而非答案泄露。本项目应把“错误定位”与“提示入口”放在同一处，避免学生面对裸红叉。
3. **提示政策需要显式化**。OATutor 明确写出“Using hints will not increase mastery credit”“AI Tutor won't affect your mastery score”，把帮助与评分解耦；这比隐藏规则更可信。
4. **掌握度呈现要可解释**。OATutor 的进度条醒目，但 11%→39% 的跳变没有依据说明；本项目若展示学情，应能展开看到“本次答对哪个技能/权重”，否则会变成装饰性数字。
5. **颜色要分两套语义**：对象身份色（Desmos/GeoGebra 的表达式色芯片、Mathos 的红/绿极值点）与对错语义色（OATutor 的绿勾/红叉）。两套混用会让“红色曲线”被误读为错误。
6. **数学排版的最小可用标准**：行内公式与正文同基线、最终答案有视觉收束（方框/加粗）、步骤编号清晰、上下标与负号不能退化为纯文本。Desmos/GeoGebra/JSXGraph/OATutor/Mathos 均达到这一标准，其中 Mathos 的“答案方框”最适合学生扫读。

### 7.2 可复用 / 不可复用

- **可复用设计思想**：对象色芯片跨“文字—列表—图形”追踪；方框最终答案；分步编号；提示阶梯折叠；提示政策文案；掌握度进度条+展开依据；图形卡内嵌在回答中；参数滑块的即时反馈。
- **不可复用**：品牌 Logo、插画、具体配色与版式；外部嵌入依赖（演示项目要求离线 0 外网请求）；GeoGebra 命令语法；OATutor 的题库与文案。

## 8. 对智学数研学生端的具体启示

1. **数学图形卡（P0）**：在 AI 回答内嵌“函数 + 极值点 + 参数滑块”的图形卡；图线与文字中的对象使用同一颜色；提供“重置/显示极值/显示切线”小开关；不跳转外部站点。
2. **答错承接（P0）**：不要只给红叉。至少给出“你填的答案与目标差在哪一步”的一句话，并在同一位置提供“看提示”入口；提示展开后仍保留学生原答案，不整页重讲。
3. **提示阶梯（P1）**：3 级左右：①指向概念/下一步问题；②给出关键中间步骤；③给出完整示范但标注“这将影响本次掌握度学分”。政策文案要常驻可见。
4. **学习状态（P1）**：保留百分比进度条，但增加“本次变化依据”（如“答对：因式分解 · 权重 0.3”）；避免无解释跳变。
5. **排版（P0）**：行内 KaTeX；最终答案方框；步骤编号；中文正文与公式混排时保持行高与基线稳定。
6. **颜色语义（P1）**：对象色与对错色分离；对错色只用于反馈图标/边框，不用于函数曲线本身。
7. **离线与合规**：以上均为设计思想复刻，不引入 Desmos/GeoGebra/JSXGraph 的在线依赖；不复制品牌素材与题库。
