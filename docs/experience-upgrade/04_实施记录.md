## 3. 与最初设计稿的偏差（如实）

1. **没有新建 GuidedStepCard / GuidedErrorCard / GuidedRemedyCard / GuidedProgress**。研究确认真实项目已有 `Socratic*` 卡片，直接复用才能保证视觉与交互契约一致；只新增 `KnowledgeTraceCard`。`02_引导式解题与知识追溯设计.md` 里的这四张卡是备选方案，未采用。
2. **练题三套全部为选择题**。原题库 `quiz_gaokao.jsonl` 的 choice 题有答案与解析，判分稳定；题3 的填空 `61/25` 仍出现在「错题本」体验里，不在练题中心。若下一轮要把练题中心扩到填空，需要做答案归一化。
3. **PPT 源只有两个课题**。`decks` 目录 13 个 pptx、11 个内容变体，只有「1.2.1 直线的点斜式方程」与「4.2.2 等差数列的前 n 项和公式」；第三套只能是直线的精简版。已在 `classroomDecks.js` 与手册中注明，没有伪称三个不同课题。
4. **课件是语义元素，不是整页截图**。按原项目 `SlideCanvas` 的 `SlideElement` 角色（definition/bullets/steps/formula/note）重建，保留原 PPT 的标题、要点、例题与讲稿；没有把 pptx 渲染成整页图。
5. **语音用浏览器中文 TTS（Microsoft Huihui 等）**，不是预生成音频。实测 Chrome 有 zh-CN 声音，`speechSynthesis.speaking=true`；若演示机没有中文 voice，设置面板会明示「讲解会静音」，不会静默假装在讲。
6. **题2 的命题瑕疵**：B 与 D 在当前条件下都成立；演示与错题记录都写「若为单选，原题可能有瑕疵」，不把 D 判错。
