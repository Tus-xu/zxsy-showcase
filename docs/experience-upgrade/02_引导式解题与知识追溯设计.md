# 02 · 引导式解题与知识追溯设计

## 1. 参考图的视觉语法

用户给的 6 张引导卡截图（`.work/refs/user-ref-12..17.png`）可以归纳为 5 种语义块：

| 块 | 颜色 | 用途 | 关键元素 |
|---|---|---|---|
| 拆解思路 / 步骤 | 紫 `--purple` + `--purple-soft` | 一步一个任务 | 步骤号、标题、说明、内嵌作答、`填完补全` / `式子输入` / `二元判断` |
| 错因分析 | 红 `--err` + `--err-bg` | 答错后的诊断 | 「这一步答错了」、原因、`计算错误 / 思维错误` 标签 |
| 知识补课 | 琥珀 `--warn` + `--warn-bg` | 前置知识缺口 | 「先补 5 分钟」、知识点名、AI 生成声明、最小例子、检验题、`原位补课 / 跳过补课` |
| 思维轨迹回放 | 白底 + 紫/绿/琥珀分段 | 复盘整条路径 | 分段进度、步骤状态、纠错/提示/补课/退出计数、`掌握路线 · 共 8 步` |
| 盲点挑战 | 白底 + 紫边 | 最后一道迁移题 | 「说说为什么」、三个解释选项、`我懂了` |

底部固定一条细进度：`第 2/3 步 引导中`，最后 `第 3/3 步 收束`。

## 2. 三步链（以题1 为例）

### 第 1 步 · 观察两条轴

- 目标：把「虚轴长是实轴长的 √7 倍」翻译成 `b/a = √7`。
- 交互：观图 + 选择。
  - 双曲线图（实轴、虚轴、渐近线），可切换显示 `2a` / `2b`。
  - 选择：`b/a = √7` / `b/a = 7` / `a/b = √7`。
- 正确反馈：绿色「对，2b=√7·2a，约掉 2 得 b/a=√7」。
- 错误反馈：红色错因块「把 2b 与 2a 的倍数直接当成 b/a 的平方 / 忘记约掉 2」。
- 知识补课（可选）：双曲线实轴/虚轴定义，2 分钟。

### 第 2 步 · 把 b/a 翻译成 e

- 目标：用 `c²=a²+b²` 推出 `e²=1+(b/a)²`。
- 交互：填空 + 符号面板。
  - 空 1：`c² = a² + ___`（填 `b²`）
  - 空 2：`e² = 1 + ___`（填 `(b/a)²`）
  - 符号面板提供 `a² b² c² e² ( ) + = /` 等 token；插入后实时 KaTeX 预览。
- 正确反馈：绿色「e²=1+7=8，e=2√2（e>0）」。
- 错误反馈：
  - 若填 `7`：红色「你把 b/a 直接当成了 e²；先平方再代入」。
  - 若填 `b/a`：红色「e 是 c/a，不是 b/a；两条轴的比例不是离心率」。
- 知识补课（可选）：`c²=a²+b²` 与 `e=c/a` 的由来。

### 第 3 步 · 回扣题目与盲点挑战

- 目标：确认答案 D，并能解释「为什么不是 C」。
- 交互：选择 + 口头解释。
  - 选择 D（2√2）。
  - 盲点挑战：`由 e=c/a=2√2 可推出什么？` A `c=2√2·a` / B `a=2√2·c` / C `c²=2√2·a²`。
- 正确反馈：绿色完成卡 + 思维轨迹回放。
- 错误反馈：红色「C 是 b/a；e 是 c/a。首答 C 的错因是把轴比当离心率」。

### KnowledgeTraceCard · 知识追溯动画

这是本轮新增的核心视觉。它不是普通进度条，而是一条「知识路径」：

```
已知            化简            桥梁              目标
2b=√7·2a  ──▶  b/a=√7   ──▶  c²=a²+b²   ──▶  e=c/a=2√2
  ✓               ✓               ⚠                ✓
一次过          一次过          卡过一次         订正后通过
```

结构：
- 标题行：`🧭 知识追溯 · 本题用了 4 个知识点` + `播放 / 暂停 / 重播`。
- 轨道：4 个节点 + 3 段连接线；连接线用 `stroke-dashoffset` 动画绘制。
- 节点：圆点 + 知识名 + 学生动作（一次过 / 卡过一次 / 看提示 / 补课）。
- 当前节点上方浮出说明气泡：「第 2 步：你把 b/a 直接当成了 e，漏了平方」。
- 底部：`已回放 2/4` + 速度（0.8× / 1×）。
- 颜色：通过=绿 `--ok`，卡壳=琥珀 `--warn`，错误=红 `--err`，未到=灰 `--ink4`。
- 动画：每 900–1200ms 前进一个节点；连接线 400ms 绘制；节点 200ms 放大/变色；说明气泡 200ms 淡入。
- 减少动效：`prefers-reduced-motion: reduce` 时一次显示全部节点，提供「上一步/下一步」按钮，不自动播放。
- 可访问性：轨道用 `role="list"`，节点 `aria-current="step"`；播放按钮 `aria-pressed`；说明文字用 `aria-live="polite"`。
- 播放结束：显示「这轮你用了 1 次纠错、1 次提示、1 次补课」，并出现「再走一遍 / 换个体验」。

数据：

```js
{
  type: 'knowledge_trace',
  title: '知识追溯',
  nodes: [
    { id: 'given',  label: '已知', detail: '2b=√7·2a', state: 'pass',  action: '一次过' },
    { id: 'ratio',  label: '化简', detail: 'b/a=√7',   state: 'pass',  action: '一次过' },
    { id: 'bridge', label: '桥梁', detail: 'c²=a²+b²', state: 'stuck', action: '卡过一次' },
    { id: 'target', label: '目标', detail: 'e=2√2',    state: 'pass',  action: '订正后通过' },
  ],
  summary: '你把轴比当成了离心率；补上平方关系后一次算对。',
}
```

## 4. 题2 / 题3 的引导形态

- 题2 正三棱柱：第 1 步观图（3D 棱柱，D 为 BC 中点），第 2 步选线面垂直判定（BC⊥AD、BC⊥AA₁），第 3 步回扣选项并说明 D 选项的干扰。若题目本身存在多解/命题瑕疵，卡片要如实标注，不硬编。
- 题3 有放回取球：第 1 步定义 X（至少取出一次的球的个数），第 2 步用指示变量求期望（每个球至少出现一次的概率 1−(4/5)³），第 3 步求和 5×61/125=61/25。交互用分布表/指示变量开关，不用强行做 3D。

## 5. 验收

- 三步走通；答错可继续；提示/补课/回放计数真实。
- 任何步骤的数学内容不出现原始 LaTeX。
- 知识追溯动画在 1440/1920 正常；reduced-motion 有静态替代。
- 对比度：正文 `--ink2` 以上；琥珀/红色浅底上的文字用深色 token。
- 键盘：所有按钮/选项可 Tab 到达，Enter/Space 可触发。
