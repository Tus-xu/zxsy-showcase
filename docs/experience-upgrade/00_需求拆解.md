### R3 · 引导式解题链路与视觉

**用户原话**：「完善整一个引导式解题的链路」「我更偏向于像我贴出来的图片那样的有颜色有分界的形式」「不同的交互形式的叠加以及知识追溯的动画播放」。

参考图（user-ref-12 至 17）的视觉语法：

- **紫色「拆解思路」块**：步骤标题 + 说明 + 内嵌交互（点选/填空/符号面板），右上角「填完补全 / 式子输入 / 二元判断」状态。
- **红色「错因分析」块**：明确指出这一步答错的原因，带「计算错误 / 思维错误」标签。
- **琥珀色「先补 5 分钟 · 知识补课」块**：前置知识、AI 生成声明、最小例子、检验小题、「原位补课 / 跳过补课」。
- **「思维轨迹回放」卡**：分段进度条、步骤状态（一次过 / 卡过一次）、纠错/提示/补课/退出计数、「掌握路线 · 共 8 步」。
- **底部进度**：`第 2/3 步 引导中`、`第 3/3 步 收束`，细进度条。
- **多交互叠加**：观图（可拖动切点）、选择、填空、符号面板、盲点挑战。

要做的：
1. 用真实项目已有 `Socratic*` 组件 + V4 token 组合出「题1 三步引导」完整链路。
2. 每一步至少有：观察/读题 → 拆解/作答 → 反馈（对/错/提示）→ 进入下一步。
3. 错答时出现红色错因块，可「看提示 / 退回上一步 / 看老师怎么说」。
4. 最后出现「思维轨迹回放」+「盲点挑战」，进度到 3/3。
5. 新增「知识追溯」动画：按步骤依次点亮，展示每一步用了哪个知识、卡在哪里、如何纠正；支持播放/暂停/重播，`prefers-reduced-motion` 下改为静态分步。

验收：
- 三步全部可走通；任意一步答错都能继续，不卡死。
- 进度、首答、订正、提示次数、补课次数真实记录并在回放中体现。
- 1440/1920 截图无溢出、对比度达标。

### R4 · 体验分类栏 + 自动填充发送

**用户描述的流程**（逐字拆）：

1. 点击某个体验对话 → 先看到「首页展示部分」。
2. 文字和图片已经编辑好放在对话框中，处于**待发送**状态。
3. 用户点发送 → 用户消息进入对话，AI 开始回答，**真实流式输出**。
4. AI 回答完 → **主动把下一条信息编辑好放进输入框**，又是待发送。
5. 用户再点发送 → 继续下一轮，直到整条链路走完。
6. 每次重新打开界面都会刷新/重置，可以反复体验。

这意味着需要一个「体验播放器」状态机，而不是现有的一次性脚本卡：

```
idle(封面) → prefilled(第 n 条待发送) → sending(用户消息入列)
→ streaming(AI 分片输出) → cards(交互卡) → prefilled(第 n+1 条) → … → done(可重播)
```

关键决策：
- 体验对话使用独立 conversation id（如 `exp-t1-guide`），与现有 `sc-*` 示例会话隔离。
- 进入时清空该体验的本地进度（或使用 `sessionStorage`），保证每次重开从封面开始。
- 预填内容包含文本 + 附件（题图），附件显示为真实缩略图。
- 发送后走现有 SSE 流式管线；分片速度可配置，确保肉眼可见。
- AI 完成后延迟约 300–600ms 再预填下一条，让用户看到「AI 说完 → 输入框出现下一句」。
- 输入框预填时按钮高亮，用户可编辑吗？演示模式下建议锁定为「直接发送」语义，仍允许修改但不影响脚本；若不修改则按脚本推进。
- 走完后显示「本轮体验完成 · 重新体验」，点击重置。

12 个体验的内容矩阵：

| 题目 \ 体验 | 知识问答 | 错题本 | 举一反三 | 引导式解题 |
|---|---|---|---|---|
| 题1 双曲线 | 为什么 e=c/a | 把 b/a 当 e | 轴比/换轴三问 | 3 步推导 |
| 题2 正三棱柱 | 线面垂直判定 | 把 AD⊥A₁C 想当然 | 线面/面面变式 | 3 步证明 |
| 题3 期望 | 有放回与至少一次 | 把 X 当二项分布 | 期望/方差变式 | 3 步计数 |

每条体验 4–8 轮，总时长 1–3 分钟。
