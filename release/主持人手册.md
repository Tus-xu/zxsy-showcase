## 1B. 学生端教学示例（本轮新增，可现场作答）

这些是**独立示例数据**，不是采证回放；标题旁会有一个「离线示例」小标（只在标题下出现一次）。
全部断网可跑，作答、换路、刷新恢复都真实生效。

打开位置：左侧会话列表「今天」分组，第一条就是主持人首选。

### 首选流程 · 导数学习 · 从提问到改错
1. 打开「导数学习 · 从提问到改错」——开场已有学生提问、题图、三段符号讲解。
2. 点讲解卡下方「可以，出三题」→ 同一线程出现三题变式卡（先换系数，再改走势，最后易误判）。
3. 第一题 V1 选 **A（−1）**→ 卡片当场判错并留痕（不会自动给答案）。
4. 点「引导式解题」→ 同一线程进入导学：圈题眼 → 读题 → 选方法 → 分步推导。
5. 走 A 路径：`判断局部极值` → `题目看懂了` → `看导数变号` → `−1 和 2` → `x=0 处的切线斜率为负` → `左正右负` → `局部极大` → `局部极小` → `x=2` → `它左侧在上升，右侧在下降`。
6. 点「回到这题」→ 重选 **C（2）**→ 出现「已订正」，首答 A 与改答 C 都在上面。
7. 想演示第二种思路，直接单独打开「引导式解题 · 为什么不是极小值」，避免重滚整条会话。

### 现场可说的边界
- 示例只对**已编排的选项与少量同义短句**作匹配。学生自由输入超出范围的答案时，会停在原步骤并提示「先选一个步骤」，不会假装理解。
- 「函数值与导数符号」小课是暂停，不是新章节；主进度仍停在「分步推导」第 3 步。
- 引导做完后主进度显示「第 4 步 / 共 4 步 · 已完成」。
